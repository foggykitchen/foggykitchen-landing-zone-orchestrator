# OCI ADB Examples

This directory contains **OCI Autonomous Database-focused payload examples** organized around access and connectivity patterns.

---

## 🎯 Purpose

The goal of this section is to group OCI ADB examples in a way that stays readable as more private access, backup, clone, and DR variants are added.

Current emphasis:

- private ADB access patterns with explicit VCN composition
- lightweight validation host patterns for private SQL*Net reachability
