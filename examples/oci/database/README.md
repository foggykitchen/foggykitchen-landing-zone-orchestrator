# OCI Database Examples

This directory contains **OCI database-focused payload examples** organized by database service and access pattern.

---

## 🎯 Purpose

The goal of this section is to group OCI database examples in a way that stays readable as more services, private access, and disaster recovery variants are added.

Current emphasis:

- private BaseDB VM system access using OCI Bastion Service
- lightweight validation host patterns for private SQL*Net reachability

New database services follow `database/<service>`. Existing Autonomous Database examples remain under `examples/oci/adb`.
