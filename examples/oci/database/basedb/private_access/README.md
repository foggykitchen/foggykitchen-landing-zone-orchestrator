# OCI BaseDB Private Access Examples

This directory contains runnable OCI BaseDB private access payload examples built on the shared `basedb_private_access` pattern.

The basic variant uses VM.BaseDB.x86, 4 ECPUs, Standard Edition, 256 GB, LVM and TCP/1521 with two private subnets, NSGs, NAT/Service Gateway and Managed SSH via OCI Bastion Service. It uses an existing compartment. Review costs before deployment.
