# Azure SQL Private Access Examples

This scenario family focuses on Azure SQL Database private access.

## Available Variants

- [private_endpoint](private_endpoint/README.md) - Private Endpoint access with one VNet, one client subnet, `AzureBastionSubnet`, one Private Endpoint subnet, one NSG, one Azure Bastion host, one Private DNS Zone, one Azure SQL logical server, one SQL database, and one validation host.

## Deferred

- secure variant with Microsoft Entra administrator, TDE customer-managed key, and diagnostics
- PostgreSQL, MySQL, and Cosmos DB
- app-to-data, multi-spoke, governance, and disaster recovery blueprint tiers
