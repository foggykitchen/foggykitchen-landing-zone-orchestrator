# Azure Event-Driven Data Pipeline Examples

This directory contains runnable wrappers for the shared `event_driven_data_pipeline` Azure pattern.

The scenario covers API Management to `fninitiator`, Event Hubs buffering, native Event Hub-triggered `fncollector`, PostgreSQL delegated-subnet persistence, and validation-only `fnvalidator`.
