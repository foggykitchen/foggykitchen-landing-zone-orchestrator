# Azure Bulk Ingestion Pipeline Examples

This directory contains runnable wrappers for the shared `bulk_ingestion_pipeline` Azure pattern.

The scenario covers Blob Storage uploads, Event Grid delivery to `fnbulkload`, Event Hubs buffering, native Event Hub-triggered `fncollector`, PostgreSQL delegated-subnet persistence, and validation-only `fnvalidator`.
