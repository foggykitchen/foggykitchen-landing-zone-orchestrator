# Azure DevOps Examples

Azure DevOps examples compose GitHub source, an ARM OIDC service connection, pipeline configuration and private Azure workload infrastructure from FoggyKitchen modules.

## Available Patterns

- [Build and deploy AKS](build_and_deploy_aks/README.md): build and smoke-test the demo image on the private jump VM, push through the ACR Private Endpoint, and deploy from a Microsoft-hosted agent through AKS Run Command.

## Start Here

Use the [basic example](build_and_deploy_aks/basic/README.md) for prerequisites, agent registration, payload, commands, live RBAC results, screenshots and teardown evidence. The existing AKS baseline patterns remain infrastructure-only.
